# Hypothesis-Testing-Experimentation
A hands-on repository covering statistical hypothesis testing, experimental design, A/B testing, and data-driven decision-making using Python.

📌 Topics Covered

Statistical Hypothesis Testing

Null & Alternative Hypotheses

Significance Level & P-Values

Type I & Type II Errors

Statistical Power

Confidence Intervals

Z-Test & T-Test

Chi-Square Test

ANOVA

One-Tailed & Two-Tailed Tests

A/B Testing

Experiment Design & Randomization

Sample Size & Minimum Detectable Effect

Conversion Rate Analysis

Statistical Significance vs. Practical Significance

Multiple Hypothesis Testing

Experiment Results & Interpretation

🛠️ Tools

Python Pandas NumPy SciPy Statsmodels Matplotlib Jupyter Notebook

🎯 Goal

Develop practical skills in statistical inference, experimentation, and evidence-based decision-making for Data Analytics, Data Science, and product-focused technical interviews.
